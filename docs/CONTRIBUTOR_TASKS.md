# Contributor Task Ideas

Create these as GitHub Issues and apply the suggested labels. Keep each issue
small enough for one focused pull request.

| Task | Suggested labels | Difficulty |
| --- | --- | --- |
| Add a power calculator using `P = W/t` | `good first issue`, `enhancement` | Beginner |
| Add test cases for negative work | `good first issue`, `tests` | Beginner |
| Improve formula explanations in the README | `good first issue`, `documentation` | Beginner |
| Add a reset-all-calculators button | `good first issue`, `enhancement` | Beginner |
| Improve keyboard focus visibility | `help wanted`, `accessibility` | Beginner |
| Add metric unit conversion helpers | `help wanted`, `enhancement` | Intermediate |
| Add elastic collision calculations | `help wanted`, `enhancement` | Intermediate |
| Add an accessible projectile trajectory graph | `help wanted`, `enhancement` | Advanced |

## Strong issue format

Every contribution issue should contain:

- a clear learner-facing problem;
- an exact scope;
- acceptance criteria;
- relevant files;
- testing expectations; and
- screenshots or formula references when useful.

Example acceptance criteria for the power calculator:

- accepts power, work and time;
- solves for exactly one missing variable;
- validates division by zero;
- shows formula, substitution and answer;
- uses watts, joules and seconds;
- includes automated tests; and
- works in both themes and on mobile.

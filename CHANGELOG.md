# Changelog

All notable changes to Dinglo Physics Solver are documented here.

## 1.2.0 — Contributor-ready release

- Replaced the proprietary licence with the MIT License.
- Rewrote the contribution guide for fork-based pull requests.
- Added structured bug-report and feature-request forms.
- Added a pull-request template.
- Added a code of conduct and security policy.
- Added contributor task ideas and a physics contribution guide.
- Added repository-health tests.

## 1.1.0 — Dark mode

- Added light and dark theme switching.
- Added automatic system-theme detection.
- Saved the learner's theme preference.
- Added dark styling across calculators, inputs and solution panels.

## 1.0.0 — Initial release

- Added mechanics calculators for forces, momentum, projectile motion, work and
  energy.
- Added step-by-step formula substitution.
- Added responsive Dinglo styling and automated formula tests.
